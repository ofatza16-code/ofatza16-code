# ระบบแจ้งลาผ่านไลน์กลุ่ม → Google Sheet → สรุปอัตโนมัติ → แดชบอร์ด

## การทำงาน
พิมพ์ในกลุ่มไลน์ → บอท (Vercel) อ่านข้อความ → ตรวจรหัสพนักงาน → บันทึกลงชีต `Leaves` ทันที → ตอบสรุปในกลุ่ม
ทุกเช้า 08:00 น. บอทส่งสรุปผู้ลาวันนั้นเข้ากลุ่ม · พิมพ์ `สรุปวันนี้` เพื่อขอสรุปเองได้ · ชีต `Dashboard` อัปเดตอัตโนมัติ

## รูปแบบข้อความ
```
ลา <รหัสพนักงาน> <ชื่อ> <ประเภท> <วันที่หรือช่วงวัน> เหตุผล <ข้อความ>

ลา EMP001 สมชาย ใจดี ป่วย 12/11 เหตุผล ไข้หวัด
ลา EMP014 สมหญิง รักงาน กิจ 14/11-15/11 เหตุผล ธุระครอบครัว
ลา EMP007 วิชัย ใจงาม พักร้อน 20/11/2026-22/11/2026
```
ประเภท: ป่วย / กิจ / พักร้อน · ปีใส่ ค.ศ. หรือ พ.ศ. ก็ได้ · ไม่ใส่ปี = ปีนี้ · ลาได้ไม่เกิน 60 วันต่อครั้ง

## ขั้นที่ 1: เตรียม Google Sheet
**ไฟล์ที่ใช้:** `template/leave-system-template.xlsx`
1. เข้า drive.google.com > ใหม่ > อัปโหลดไฟล์ > เลือกไฟล์เทมเพลต
2. ดับเบิลคลิกไฟล์ที่อัปโหลด > ไฟล์ > **บันทึกเป็น Google ชีต** (ต้องทำ ไม่งั้นบอทเขียนไม่ได้)
3. ตั้งชื่อไฟล์ "ระบบแจ้งลา"
4. ชีต `Employees`: ลบแถวตัวอย่าง แล้วกรอกพนักงานจริง (รหัส / ชื่อ-นามสกุล / แผนก) รหัสห้ามซ้ำและห้ามเว้นวรรค
5. ชีต `Quota`: ปรับโควตาถ้าต้องการ (ค่าเริ่มต้น ป่วย 30, กิจ 3, พักร้อน 6)
6. ชีต `Leaves`: **ลบแถวที่ 2 (ข้อมูลตัวอย่าง)** ก่อนใช้งานจริง ห้ามลบหัวตาราง ห้ามเปลี่ยนรูปแบบวันที่ yyyy-mm-dd
7. คัดลอก **Spreadsheet ID** จาก URL (ช่วงระหว่าง `/d/` กับ `/edit`) เก็บไว้
8. ตรวจชีต `Dashboard`: ถ้ากราฟไม่ขึ้นหลังนำเข้า ให้เลือกตารางวันลารายเดือน (A10:B22) > แทรก > แผนภูมิ และตารางตามประเภท (A26:B29) > แทรก > แผนภูมิ

## ขั้นที่ 2: สร้างบอทไลน์ (Messaging API)
**ไฟล์ที่ใช้:** ไม่มี (ทำบนเว็บ)
1. เข้า developers.line.biz > ล็อกอิน > สร้าง Provider > สร้าง Channel ประเภท **Messaging API**
2. แท็บ Basic settings: คัดลอก **Channel secret**
3. แท็บ Messaging API: กด Issue **Channel access token (long-lived)** แล้วคัดลอก
4. แท็บ Messaging API: เปิด **Allow bot to join group chats**
5. ที่ LINE Official Account Manager > ตั้งค่าการตอบกลับ: ปิด "ข้อความตอบกลับอัตโนมัติ" และ "ข้อความต้อนรับ"
6. สแกน QR code ของบอท เพิ่มเป็นเพื่อน แล้วเชิญเข้ากลุ่มพนักงาน

## ขั้นที่ 3: ให้บอทเข้าถึงชีต (Google Service Account)
**ไฟล์ที่ใช้:** ไม่มี (ทำบนเว็บ)
1. console.cloud.google.com > สร้างโปรเจกต์ใหม่
2. APIs & Services > Library > เปิด **Google Sheets API**
3. IAM & Admin > Service Accounts > Create > ตั้งชื่อ เช่น leave-bot > Done
4. เข้า service account นั้น > Keys > Add key > Create new key > **JSON** (ไฟล์จะดาวน์โหลดลงเครื่อง)
5. เปิดไฟล์ JSON คัดลอก `client_email` และ `private_key`
6. กลับไป Google Sheet > แชร์ > ใส่อีเมล `client_email` ให้สิทธิ์ **ผู้แก้ไข**
7. อย่าอัปโหลดไฟล์ JSON ขึ้น GitHub

## ขั้นที่ 4: เตรียมตัวแปรค่าตั้ง
**ไฟล์ที่ใช้:** `.env.example`

| ตัวแปร | ค่า | ได้จาก |
|---|---|---|
| LINE_TOKEN | Channel access token | ขั้น 2 ข้อ 3 |
| LINE_SECRET | Channel secret | ขั้น 2 ข้อ 2 |
| GOOGLE_CLIENT_EMAIL | client_email | ขั้น 3 ข้อ 5 |
| GOOGLE_PRIVATE_KEY | private_key ทั้งก้อน (รวม `\n`) | ขั้น 3 ข้อ 5 |
| SHEET_ID | Spreadsheet ID | ขั้น 1 ข้อ 7 |
| LINE_GROUP_ID | ID กลุ่ม | ขั้น 8 (ว่างไว้ก่อน) |
| CRON_SECRET | สตริงสุ่มยาว 20 ตัวอักษรขึ้นไป | ตั้งเอง |
| BIND_LINE_USER | `true` = ผูกรหัสกับบัญชีไลน์กันแจ้งลาแทนกัน (ค่าเริ่มต้น false) | ตั้งเอง |

## ขั้นที่ 5: นำโค้ดขึ้น GitHub
**ไฟล์ที่ใช้:** ทั้งโฟลเดอร์ (ยกเว้น template/ ใส่หรือไม่ใส่ก็ได้)
1. (ทางเลือก) ทดสอบในเครื่อง: `npm install` แล้ว `npm test` ต้องขึ้น `ALL TESTS PASSED`
2. สร้าง repo ใหม่บน GitHub (แนะนำ Private)
3. อัปโหลดไฟล์ทั้งหมดขึ้น repo (หรือ `git init`, `git add .`, `git commit`, `git push`) ตรวจว่าไม่มี `.env` หรือไฟล์ JSON ของ service account ติดไป

## ขั้นที่ 6: Deploy บน Vercel
**ไฟล์ที่ใช้:** `vercel.json`, `.env.example`
1. vercel.com > Add New > Project > Import repo นี้
2. Framework Preset: **Other** (ไม่ต้องตั้ง build command)
3. ใส่ตัวแปรจากตาราง ขั้น 4 ในช่อง Environment Variables (ยังไม่ต้องใส่ LINE_GROUP_ID)
4. กด Deploy แล้วจดโดเมน เช่น `https://leave-bot.vercel.app`
5. เปิด `https://<โดเมน>/api/webhook` ในเบราว์เซอร์ ต้องเห็นคำว่า `ok`

## ขั้นที่ 7: เชื่อม Webhook และตั้งเวลาสรุปรายวัน
**ไฟล์ที่ใช้:** `vercel.json`
1. LINE Developers > Messaging API > Webhook URL ใส่ `https://<โดเมน>/api/webhook` > กด Update > **Verify** (ต้องขึ้น Success) > เปิด **Use webhook**
2. Cron ใน `vercel.json` ตั้งไว้ `0 1 * * *` = 08:00 น. เวลาไทยทุกวัน (Vercel ใช้เวลา UTC) ตรวจได้ที่ Project > Settings > Cron Jobs
3. แพ็กเกจ Hobby ของ Vercel รันได้วันละครั้ง ซึ่งพอสำหรับงานนี้

## ขั้นที่ 8: หา Group ID แล้วล็อกบอทให้ทำงานกลุ่มเดียว
1. ในกลุ่มไลน์พิมพ์ `/groupid` บอทตอบ `Group ID: Cxxxx...`
2. ใส่ค่านั้นเป็น `LINE_GROUP_ID` ใน Vercel > Settings > Environment Variables
3. Deployments > Redeploy (ตัวแปรใหม่มีผลหลัง deploy ใหม่เท่านั้น)
4. หลังนี้บอทจะรับคำสั่งเฉพาะกลุ่มนี้ และ `/groupid` จะเลิกตอบ

## ขั้นที่ 9: ทดสอบทั้งระบบ
| ทดสอบ | พิมพ์ | ผลที่ควรได้ |
|---|---|---|
| ลาปกติ | `ลา EMP001 สมชาย ใจดี ป่วย 12/11 เหตุผล ทดสอบ` | แถวใหม่ในชีต Leaves + บอทตอบสรุปพร้อมยอดคงเหลือ |
| หลายวัน | `ลา EMP001 สมชาย ใจดี กิจ 14/11-16/11` | จำนวนวัน = 3 |
| รหัสผิด | `ลา EMP999 ทดสอบ ป่วย 12/11` | ตอบว่าไม่พบรหัสพนักงาน ไม่บันทึก |
| วันที่ผิด | `ลา EMP001 สมชาย ป่วย 31/02` | ตอบว่าวันที่ไม่ถูกต้อง |
| รูปแบบผิด | `ลา ป่วย 12/11` | ตอบวิธีพิมพ์ที่ถูก |
| สรุปรายวัน | `สรุปวันนี้` | ตอบรายชื่อผู้ลาวันนี้ |
| แดชบอร์ด | เปิดชีต Dashboard | KPI กราฟ และตารางรายคนอัปเดต |
| cron | Vercel > Settings > Cron Jobs > Run | ได้ข้อความสรุปเข้ากลุ่ม |

เสร็จแล้ว **ลบแถวทดสอบในชีต Leaves** ก่อนใช้งานจริง

## แก้ปัญหาที่พบบ่อย
| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| Verify webhook ไม่ผ่าน | โดเมนผิด หรือ LINE_SECRET ผิด (ตรวจลายเซ็นไม่ผ่านจะได้ 401) |
| บอทเงียบ | ยังไม่เปิด Use webhook / ยังไม่ได้ปิดตอบกลับอัตโนมัติ / LINE_GROUP_ID ไม่ตรงกลุ่ม |
| บอทตอบ "ระบบขัดข้อง" | ดู Vercel > Logs: มักเป็นยังไม่ได้แชร์ชีตให้ client_email, SHEET_ID ผิด, หรือชื่อชีตไม่ตรง (Leaves, Employees, Quota) |
| private key error | ต้องวางทั้งก้อนรวม `-----BEGIN...-----END` และ `\n` ตามไฟล์ JSON |
| สรุปรายวันไม่ส่ง | ไม่ได้ตั้ง LINE_GROUP_ID หรือ CRON_SECRET ไม่ตรง / ยังไม่ Redeploy |
| ชื่อในชีตไม่ตรงที่พิมพ์ | ตั้งใจ: บอทใช้ชื่อทางการจากชีต Employees ตามรหัส |
| ผูกบัญชีไลน์ผิดคน | ลบค่าในคอลัมน์ D ของชีต Employees แถวนั้น แล้วให้เจ้าตัวแจ้งลาใหม่ |

## ข้อจำกัด
- ยังไม่รองรับลาครึ่งวัน การแก้ไข/ยกเลิกการลาผ่านไลน์ และการอนุมัติ (แก้ในชีตโดยตรงได้)
- นับวันลาตามปีของวันเริ่มลา การลาข้ามปีนับทั้งหมดเข้าปีของวันเริ่ม
- นับทุกวันตามปฏิทิน ไม่หักวันหยุด
- แดชบอร์ดอ่านข้อมูลได้ 2,000 แถว และรายคน 50 คน ถ้าเกินให้ลากสูตรต่อ
